# Navigation Specification

**Status:** Draft v1

---

# Overview

Navigation should remain simple, predictable and always visible.

The user should never lose orientation.

---

# Primary Navigation

Primary destinations include

- Home
- Movies
- Series
- Collections
- Continue Watching
- Favorites
- Watchlist
- Search
- Settings

---

# Secondary Navigation

Context dependent navigation includes

- Genres
- Studios
- Actors
- Years
- Languages
- Recently Added
- Trending

---

# History Navigation

Desktop navigation supports

- Back
- Forward

History behaves similarly to a web browser.

---

# Breadcrumbs

Detail pages may display breadcrumbs.

Example

Home

↓

Series

↓

Breaking Bad

↓

Season 2

↓

Episode 5

---

# Search Access

Search should always be accessible.

Opening search must never interrupt playback.

---

# Keyboard Navigation

All navigation elements support

- Tab
- Arrow Keys
- Enter
- Escape

---

# Controller Navigation

Future versions support

- D-Pad
- Analog Stick
- Confirm
- Back

---

# Navigation States

Every navigation item has

- default
- hover
- focused
- selected
- disabled

---

# Deep Navigation

Users may navigate

Home

↓

Genre

↓

Movie

↓

Actor

↓

Collection

↓

Series

↓

Episode

without returning to the home page.

---

# Quick Actions

Navigation provides fast access to

- Resume playback
- Continue Watching
- Recently Added
- Random Movie
- Random Series

---

# User Menu

The user menu contains

- profile
- preferences
- playback settings
- logout

---

# Future Expansion

Future versions define

- animations
- focus movement
- shortcuts
- accessibility
- controller behavior
- navigation hierarchy diagrams
