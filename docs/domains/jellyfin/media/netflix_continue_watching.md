# Continue Watching Specification

**Status:** Draft v1

---

# Overview

Continue Watching provides immediate access to unfinished media.

It is one of the highest priority sections within the Media Domain.

---

# Objectives

Users should be able to

- resume instantly
- continue on another device
- remove items
- manage viewing history

---

# Resume Information

Each entry displays

- artwork
- title
- episode information
- watched progress
- remaining runtime
- last watched date

---

# Resume Action

Selecting an item resumes playback from the stored position.

Users may also restart from the beginning.

---

# Supported Media

Continue Watching supports

- Movies
- Series
- Episodes

---

# Synchronization

Playback progress is synchronized through Jellyfin.

Progress should remain consistent across all devices.

---

# Management

Users may

- remove an item
- mark as finished
- restart
- favorite
- open details

---

# Automatic Updates

The list updates whenever

- playback begins
- playback ends
- progress changes
- media is completed

---

# Ordering

Items are ordered primarily by

- most recently watched
- unfinished status

Future versions may support custom ordering.

---

# Completed Media

Completed media automatically leaves the section unless configured otherwise.

---

# Empty State

If nothing is in progress

The interface displays

- recently added media
- recommendations
- quick access to the library

---

# Integration

Continue Watching appears in

- Home
- User Profile
- Recommendations
- Search (Future)

---

# Future Expansion

Future versions define

- cross-device resume
- predictive recommendations
- timeline previews
- resume thumbnails
- intelligent ordering
- personalized prioritization
