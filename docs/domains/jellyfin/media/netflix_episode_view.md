# Episode View Specification

**Status:** Draft v1

---

# Overview

Episode View provides detailed information for a single episode before playback begins.

---

# Objectives

The page should present

- episode information
- playback controls
- technical metadata
- navigation to neighboring episodes

---

# Header

Contains

- episode thumbnail
- title
- episode number
- season number
- runtime

---

# Playback Actions

Available actions

- Play
- Resume
- Restart
- Next Episode
- Previous Episode

---

# Episode Description

Displays a concise summary of the episode.

---

# Technical Metadata

Includes

- resolution
- HDR
- audio formats
- subtitle languages
- runtime

---

# Navigation

Users can move directly to

- previous episode
- next episode
- season overview
- series overview

---

# Progress

Displays

- watched state
- completion percentage
- remaining runtime

---

# Recommendations

Possible recommendations

- Next Episode
- Related Episodes
- Similar Series

---

# Error States

Dedicated states exist for

- unavailable episode
- missing file
- playback error
- permission denied

---

# Future Expansion

Future versions define

- autoplay behavior
- transitions
- animations
- keyboard navigation
- controller support
- accessibility
- layout measurements
