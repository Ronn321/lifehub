# Series Detail Page

**Status:** Draft v1

---

# Overview

Series pages organize seasons and episodes while maintaining a cinematic presentation.

---

# Objectives

Users should quickly understand

- what the series is about
- how many seasons exist
- where they left off
- which episode plays next

---

# Header

Contains

- backdrop
- poster
- title
- description
- genres
- release years
- total seasons

---

# Primary Actions

Available actions

- Resume
- Play From Beginning
- Favorite
- Watchlist
- Trailer

---

# Season Navigation

Users can switch between seasons instantly.

The current season remains highlighted.

---

# Episode List

Each episode displays

- thumbnail
- episode number
- title
- runtime
- watched progress
- short description

---

# Resume Logic

If partially watched

Resume continues at the most recently viewed episode.

---

# Recommendations

Displays

- Similar Series
- Same Genre
- Same Cast
- Same Studio

---

# Metadata

Includes

- creators
- actors
- genres
- production years
- ratings
- technical information

---

# Future Expansion

Future versions define

- season switching animations
- episode layouts
- automatic scrolling
- keyboard behavior
- responsive layouts
