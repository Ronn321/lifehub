# Movie Detail Page

**Status:** Draft v1

---

# Overview

Selecting a movie opens a dedicated detail page.

The page combines metadata, artwork and playback actions.

---

# Objectives

The Movie page should answer

- What is this movie?
- Can I watch it now?
- Is it part of a collection?
- Who created it?
- What should I watch next?

---

# Header Section

The page begins with a cinematic header containing

- backdrop image
- poster
- title
- original title
- tagline
- short description

---

# Primary Actions

Available actions include

- Play
- Resume
- Trailer
- Add to Watchlist
- Favorite
- Mark as Watched
- More Options

---

# Metadata

Displayed information includes

- Release Year
- Runtime
- Rating
- Genres
- Studio
- Director
- Cast
- Resolution
- Audio Formats
- Subtitle Availability

---

# Description

A detailed synopsis explains the movie without cluttering the interface.

---

# Cast Section

Displays major actors.

Selecting an actor opens their dedicated page.

---

# Technical Information

Includes

- codecs
- bitrate
- resolution
- HDR
- subtitles
- audio tracks

---

# Related Content

Recommendations include

- Similar Movies
- Same Director
- Same Cast
- Same Genre
- Collection Members

---

# Context Menu

Additional actions

- Refresh Metadata
- Download
- Share
- Open in Jellyfin
- Report Problem

---

# Playback Integration

Playback should resume from the last watched position whenever possible.

---

Future versions define
