# Collections Specification

**Status:** Draft v1

---

# Overview

Collections organize related media into meaningful groups.

Collections may originate from Jellyfin or be created by users.

---

# Objectives

Collections help users

- organize libraries
- browse franchises
- discover related content
- group personal favorites

---

# Collection Types

Supported collections include

- Franchises
- Universes
- Director Collections
- Studio Collections
- User Collections
- Smart Collections
- Jellyfin Collections

---

# Collection Page

Each collection displays

- artwork
- title
- description
- media count
- member list

---

# Collection Members

Collections may contain

- Movies
- Series
- Mixed Media

---

# Sorting

Collection items support

- Release Order
- Alphabetical
- Manual Order
- Recently Added

---

# Filtering

Users may filter collections by

- Genre
- Year
- Studio
- Favorite
- Watched

---

# User Collections

Users may create

- private collections
- shared collections (Future)
- temporary collections

---

# Smart Collections

Future smart collections update automatically based on

- Genre
- Studio
- Year
- Rating
- Watch Status

---

# Collection Actions

Supported actions

- Open
- Play All
- Shuffle
- Favorite
- Edit
- Delete

---

# Integration

Collections integrate with

- Home
- Search
- Recommendations
- Library

---

# Future Expansion

Future versions define

- custom artwork
- drag and drop
- collaborative collections
- nested collections
- automatic categorization
